# BabbelStream 0.5.3

A clean rebuild for the Apple Silicon, non-notarized pilot.

## Changes

- Remove private names, company-specific configuration and branding from the public source and app.
- Replace recorded benchmark audio with synthetic speech and add public repository hygiene checks.
- Preserve saved provider and transcription-routing settings. When upgrading directly from a version without saved routing to a LiteLLM namespace, select **LiteLLM (openai/ model prefix)** once in Settings.
- Remove local build paths from executable debug maps and Finder installer metadata.
- Restore the illustrated DMG download and Homebrew installation. Nothing is auto-sent.

## Install or update

```sh
brew update
brew install --cask sichgeis/tap/babbelstream
# For an existing Homebrew installation:
brew upgrade --cask sichgeis/tap/babbelstream
```

For manual installation, download `BabbelStream-0.5.3.dmg` and its checksum. From
the download folder, verify `shasum -a 256 -c BabbelStream-0.5.3.dmg.sha256`.
Quit the old app, drag BabbelStream into Applications, eject the image and launch
the Applications copy. Preserve local settings and Keychain entries.

Apple Silicon only; macOS 13.0 or later. Version **0.5.3**, build **11**, tag
**v0.5.3**. The app is ad-hoc signed and **not notarized by Apple**. macOS may
require explicit per-app approval, and Microphone/Accessibility or Keychain
approval may need refreshing after an upgrade. Follow supported macOS approval;
do not disable security protections or remove quarantine. Managed Macs may require IT approval.

Provider use requires your own approved endpoint and API key and may incur costs.
Review every draft before sending. Older 0.5.1/0.5.2 installer downloads are withdrawn.
