# BabbelStream 0.6.1

GPT-6 Luna is now the default for remote cleanup, with reasoning disabled.
The revised prompt preserves mixed German-English wording, negation, numbers,
technical terms and repetitions used for emphasis. The two GPT-4o mini default
aliases upgrade to the corresponding Luna IDs on first launch. Check the cleanup
model in Provider Settings if your proxy uses a custom alias.

- When the original recording target is unavailable, BabbelStream keeps the
  draft available to copy. Dictation stays an unsent draft.
- Failed Recordings shows the original transcription selection and the current
  retry destination. Escape cancels a retry, and a failed export preserves the
  prior file.
- On-device processing now shows when Qwen is cleaning up the draft.

This Apple Silicon pilot is ad-hoc signed and non-notarized. Remote dictation
requires macOS 13 or later and a configured provider. Optional on-device models
require macOS 14 or later. macOS may request per-app approval or renewed permission
after installation. Managed Macs may require IT approval.

Finish any dictation or recovery work and quit BabbelStream normally before
updating. Homebrew users can run:

```sh
brew update
brew upgrade --cask sichgeis/tap/babbelstream
open /Applications/BabbelStream.app
```

For a first install, run `brew install --cask sichgeis/tap/babbelstream`.
For a manual install, download the DMG and its checksum below, verify them
with `shasum -a 256 -c BabbelStream-0.6.1.dmg.sha256`, then drag the app
to Applications. See the [setup guide](https://github.com/sichgeis/babbelstream/blob/main/docs/getting-started.md).
