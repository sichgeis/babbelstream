# BabbelStream 0.5.1 — colleague pilot (not notarized)

Apple Silicon only. This build is ad-hoc signed and has **not been notarized by
Apple**. macOS may block first launch; managed Macs may require IT approval.
This is a small colleague pilot, not an Apple-verified installer.

## Changes

- First-run permission setup, local sample-paste test and permission repair.
- Subtle adaptive Settings/dialog surfaces and balanced spacing.
- Clipboard-based insertion for all applications, with focus/cancellation guards.
- Provider destination, credential and response safeguards.
- 0.5.1 fixes the missing Allow Microphone action on first use.

Nothing is auto-sent. See CHANGELOG.md for the full feature history.

## Install and set up

Download the DMG and checksum assets. From their download folder, run
`shasum -a 256 -c BabbelStream-0.5.1.dmg.sha256`. Quit old copies, copy the app into
Applications, eject the image, and open the Applications copy.

If macOS blocks it, use [Apple's per-app Open Anyway process](https://support.apple.com/en-gb/102445)
where your device policy permits. Do not disable Gatekeeper or remove quarantine.
If approval is unavailable on a company Mac, contact IT.

Use onboarding to grant Microphone/Accessibility access, configure your own
approved provider/key, and try the local paste test. Provider use may incur costs;
no company destination or shared key is included. Test dictation only with content
and a provider you are authorized to use. Review every draft before sending.

## Updates and rollback

Homebrew installation/updates will be available from `sichgeis/homebrew-tap` after
pilot validation. Finish current work and quit before upgrading. Recheck version,
permissions and provider configuration afterward; Keychain access may prompt again.
For rollback, quit and restore a known-good prior app without deleting local data.
Homebrew's version record may need reconciliation after a manual rollback.
No in-app updater or background update traffic is added.
