# BabbelStream 0.6.0

Dictate and clean up text directly on your Mac without an API key.

- Parakeet Ultra provides local speech recognition with a verified model download,
  preparation, cancellation and removal in Provider Settings.
- Optional Qwen3.5-4B cleanup adds punctuation and light editing locally, preserves
  multilingual technical wording and uses your personal dictionary.
- Native inference has networking disabled. Cleanup failure returns raw text and
  preserves the stopped recording for retry. Dictation never sends your draft.
- Existing remote providers and saved configuration remain available.

Local inference requires Apple Silicon and macOS 14 or later. Parakeet downloads
approximately 632 MB; optional Qwen cleanup downloads 2.74 GB separately. Ollama,
Python and Xcode are not required to run the app. Qwen-ASR and Granite speech
runtime builds remain deferred.

This is an ad-hoc signed, non-notarized pilot. macOS may require explicit app and
microphone/Accessibility approval after installation or upgrade. Public installer
publication and the Homebrew update await validation on the second Mac.
