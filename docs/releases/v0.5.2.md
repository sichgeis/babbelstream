## Install and set up

Homebrew: `brew update && brew upgrade --cask sichgeis/tap/babbelstream`
(or `brew install --cask sichgeis/tap/babbelstream` for a new installation).

DMG: download `BabbelStream-0.5.2.dmg` and its checksum. From their download
folder, run `shasum -a 256 -c BabbelStream-0.5.2.dmg.sha256`. Quit old copies,
drag the app onto Applications, eject the image, and open the Applications copy.

If macOS blocks it, use [Apple's per-app Open Anyway process](https://support.apple.com/en-gb/102445)
where your device policy permits. Do not disable Gatekeeper or remove quarantine.
If approval is unavailable on a company Mac, contact IT.

If Keychain asks for your password after every restart, follow the
[targeted Keychain repair](https://github.com/sichgeis/babbelstream/blob/main/README.md#keychain-asks-for-your-password-after-every-restart).
For rollback, quit and restore a known-good prior app without deleting local data.
No in-app updater or background update traffic is added.
